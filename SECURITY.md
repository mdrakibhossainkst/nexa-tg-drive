# Security Policy

## Supported versions

Only the latest release of Nexa TG Drive receives security fixes.
If you are on an older version, update to the latest release first —
the app offers in-app updates, including from the login screen.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Report it privately, using either of these:

1. **GitHub private vulnerability reporting** (preferred): on the
   repository page, go to **Security → Report a vulnerability**.
2. **WhatsApp** the owner directly: <https://wa.me/8801920363264>

Please include:

- What the problem is and where it happens (which feature, which version)
- Steps to reproduce it, if you can
- A screenshot or error text, if there is one

You will get a reply as soon as the report has been reviewed. Please
give the owner time to fix the problem before telling anyone else
about it.

## What is never collected

Nexa TG Drive never collects your Telegram credentials, phone number,
file names, or message content. The optional owner device-stats ping
sends only anonymous install data (OS, architecture, app version, last
seen) and is on by default, but can be switched off in Settings. See
[docs/DEVICE_STATS.md](docs/DEVICE_STATS.md).
